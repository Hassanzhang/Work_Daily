9. 反模式清单 · DO NOT

❌模式代替方案
❌蓝紫渐变背景 / 蓝紫强调色朱红 #B22222 单色
❌全药片 Pill 按钮（大圆角按钮）6px 克制圆角
❌玻璃模糊 (backdrop-filter: blur)纯色 + 单层阴影
❌多层阴影 / shadow-lg / shadow-xl仅两层: shadow-card 或 shadow-raised
❌纯白卡片 (#ffffff)牛皮纸色 #F1EFE9
❌冷灰底色 (#f5f5f5)暖白 #FAFAF6
❌人物插图 / SVG 角色纯 UI，无人物
❌emoji 装饰图标文字 + 色条 + 圆点
❌虚构生产力指标 / 填充数据真实标签 + 简洁数字
❌引入外部字体（Google Fonts 等）系统字体 SF Pro / PingFang SC

10. 设计原则

01
一个强调色
朱红是唯一最强信号，不与任何其他颜色争抢。
02
左边界线
任务项通过 3px 左边框传达状态和优先级。
03
纸张底色
卡片用牛皮纸色而非纯白，营造温暖纸质感。
04
字体一致
全站使用系统字体，不引入外部字体。
05
少即是多
阴影、圆角、动效都保持最低必要量。
